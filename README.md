Se crea la clase Paciente con los atributos y métodos necesarios para almacenar y validar la información de los animales, esta clase heredan Perro, Gato y AveExotica

En la clase Hospital se inicializan los datos necesarios y se desarrolla la lógica para administrar los pacientes, controlar el ingreso, verificar que no se supere el límite permitido y asignar jaulas según el tamaño y la zona correspondiente.

También se implementan funcionalidades para validar los datos de los pacientes, controlar la medicación y las dosis acumuladas, actualizar el estado durante el tratamiento y gestionar el alta, liberando la jaula y actualizando la lista de pacientes.


Se utilizó inteligencia artificial como apoyo para agilizar la creación de funciones, organizar la estructura de las clases y desarrollar las validaciones, revisando el código para adaptarlo a los requisitos del ejercicio.
